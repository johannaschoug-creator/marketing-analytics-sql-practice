# Marketing Analytics SQL Practice

This repository contains beginner SQL projects focused on marketing analytics, campaign performance, customer retention, and business growth analysis.

## Projects

### Campaign Performance Analysis

This project practices SQL analysis around:

- Click-through rate (CTR)
- Conversion rate
- Cost per acquisition (CPA)
- Return on ad spend (ROAS)
- Campaign profitability

Technologies:
- SQL
- GitHub

Purpose:
Building hands-on SQL skills for marketing analytics and growth strategy.
